## 🩷 Practical Work & Explanations

### ୨୧ 01. Box Element and Float

This exercise introduces the use of HTML `div` elements and CSS properties for arranging boxes.

- `float` is used to position elements to the left or right.
- `clear` prevents an element from being positioned alongside floated elements.
- Different background colors help distinguish the boxes.

**File:** `lab4_box.html`

### ୨୧ 02. Website Layout

This exercise builds a simple website structure using HTML semantic elements.

| Element | Function |
|:--|:--|
| `header` | Displays the website title. |
| `nav` | Contains navigation links. |
| `section` | Groups related content. |
| `article` | Represents article content. |
| `aside` | Contains supplementary content, such as a sidebar. |
| `footer` | Displays information at the bottom of the page. |

The CSS stylesheet controls the website width, spacing, colors, typography, and positioning.

### ୨୧ 03. Sidebar Widgets

The sidebar contains a widget with navigation links and another widget with text.

CSS is used to style the widget headers, links, borders, and spacing to make the sidebar easier to read.

### ୨୧ 04. Content Cards

Three content cards are arranged in the main content area. Each card contains an image, a heading, a short description, and a detail link.

CSS controls the card width, alignment, spacing, and image shape.

### ୨୧ 05. Article Section

The article section contains article headings, images, and paragraphs.

The `float` property is used to position images beside article text, while margins and borders help separate the articles.

### ୨୧ 06. About and Contact Pages

**About** presents a simple description of the website.

**Contact** contains a form with fields for a name, email address, and message, along with a submit button.

Both pages use the same `style.css` file to maintain a consistent website appearance.
